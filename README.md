# 4 month old TIvsC
This branch contains files from differential analysis of DNA from white blood cells collected from heifers that had been transiently infected with BVDV at 175 days of gestation and control heifers. This analysis is paired with data that can be accessed on the NCBI GEO Database (GSE288374) and publication titled "Postnatal epigenetic differences in calves following transient fetal infection with bovine viral diarrhea virus."
